Thripshaw’s Disease

Problems with words? Problems with people? Hate someone so much? The psychiatrist has a name for it.

Thripshaw’s Disease — the disease where, if you can hardly talk normaly because you hate someone, you need to book a psychiatrist’s appointment for it. It is comically named, and it is named exactly that: Thripshaw’s Disease.
