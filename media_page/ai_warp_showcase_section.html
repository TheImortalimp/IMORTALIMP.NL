Use the modes on the voice canvas

  1. Open the engine and enable one or more voice rails so they draw graphics on the Canvas.
  2. Turn AI WARP on, set Warp Strength above zero, and choose a mode from the selector or cycle modes with W.
  3. The render order is source → active voices → Ghost/V-Sync → AI Warp. Thus the Warp mode transforms the graphics produced by the active voice canvas.
YouTube browser limitation: an embedded YouTube player is cross-origin. The browser does not allow its video pixels to be read by Canvas, so the 29 Canvas modes cannot directly warp the iframe’s pixels. When YouTube is embedded without capture, the CSS Warp Bus can style the player shell, while AI Warp modes process enabled voice-canvas graphics over the page. These are separate layers—not a claim that Canvas is processing the protected YouTube picture.
To run the original pixel FX on YouTube itself: open the video in a separate tab or window, return to the engine, choose FULL FX: CAPTURE YT TAB, and select that source in the browser’s sharing picker. Include tab audio for audio-reactive effects. Do not capture the engine’s own tab, which can create recursive feedback.

Other features

Play local media, use the YouTube knowledgebase, capture a browser tab/window, monitor microphone input, save user presets, export frames, and use keyboard shortcuts. Browser capture requires a secure context (HTTPS or localhost) and user permission.
