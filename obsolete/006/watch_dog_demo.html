<script>
  const effect = new WatchDogsEffect('your-container-id', {
    primaryColor: '#00d9ff',
    secondaryColor: '#ffffff',
    backgroundColor: '#000000',
    glitchIntensity: 0.7,
    autoStart: true,
    loopAnimation: true
  });
</script>

AVAILABLE METHODS

  • effect.start() - Start animations
  • effect.stop() - Stop animations
  • effect.triggerGlitch(duration) - Manual glitch trigger
  • effect.addHackingText(text, x, y) - Add custom text
  • effect.setColors(primary, secondary, bg) - Change colors
  • effect.toggleLayer(name, visible) - Toggle layers
  • effect.destroy() - Clean up and remove
